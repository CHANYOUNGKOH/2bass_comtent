작업 기록 가이드

포스팅 등록 →
작업 중 이것만 메모해두면 블로그가 자동으로 완성됩니다
Tier 1 — 필수 (없으면 블로그 생성 불가)
1. 차량 정보 ⭐ 필수
→ vehicle.brand, vehicle.model
뭘 기록?
브랜드 + 정확한 모델명
예시
"그랜저 TG" (O)  vs  "그랜저" (Δ) — 세대 구분 필수
블로그 효과
제목에 차량명 포함 → SEO 검색 유입 핵심.
"그랜저 TG 브레이크 업그레이드" 같은 제목 자동 생성
2. 작업 유형 ⭐ 필수
→ work.type
뭘 기록?
정확한 작업명
예시
"풀셋 브레이크 업그레이드", "패드 교체", "디스크 연마"
블로그 효과
블로그 구조 자체를 결정 (기술심화형 vs 유지보수형 vs 사례형)
3. 사용 부품 ⭐ 필수
→ work.parts[]
뭘 기록?
장착한 부품 전부 (브랜드 + 모델명)
예시
"브렘보 GT 6P 캘리퍼", "EBC 옐로우스텁 패드", "DBA 4000 T3 디스크"
블로그 효과
해시태그 자동 매칭 (#브렘보캘리퍼 420회/월)
부품 구매 CTA 링크 활성화, 블로그 타입 결정
4. 작업 메모 ⭐ 필수
→ originalText
뭘 기록?
자유롭게 — 작업 과정, 특이사항, 고객 대화, 느낀 점
예시
"너클이 비대칭이라 브라켓 직접 제작. 기존 BMW용 브렘보 6P를 이식. 시운전 후 재점검 완료. 차주분이 제동감에 만족"
블로그 효과
블로그 본문의 100% 소스. 여기 없는 내용은 블로그에 절대 안 나옴.
구체적일수록 글이 풍부해짐
💡 꿀팁: 음성메모 → 텍스트 변환도 OK. 3줄이면 얇은 글, 10줄이면 풍부한 글
Tier 2 — 권장 (블로그 퀄리티 UP)
5. 핵심 포인트 권장
→ keyPoints[]
뭘 기록?
이 작업에서 강조하고 싶은 점 (줄바꿈 구분)
예시
"중복투자 방지 / 맞춤형 제작 / 시운전 후 재점검"
블로그 효과
팩트시트 키워드로 활용. 4개 이상이면 "교육형" 블로그 톤 활성화
6. 난이도 권장
→ difficulty
뭘 기록?
하 / 중하 / 중 / 중상 / 상
블로그 효과
"상" 선택 → "기술 심화형" 블로그 (더 길고 전문적)
"하~중" → "유지보수 가이드형" (쉬운 설명 톤)
7. 순정↔튜닝 스펙 비교 권장
→ salesContext.specComparison
뭘 기록?
Before 스펙 / After 스펙 / 체감 차이
예시
"순정 280mm → 355mm 디스크 + 브렘보 4P / 제동거리 30% 단축"
블로그 효과
"부품 비교형" 블로그 활성화 — 가장 설득력 있는 구조.
수치가 있으면 신뢰도 극대화
8. 사진 + 단계 태그 권장
→ images
뭘 기록?
작업 전/중/후 사진. 최소 3장 권장
단계
입고 → 분해(Before) → 장착(During) → 완성(After) → 시운전
블로그 효과
단계별로 블로그 본문에 자동 배치. 사진 없으면 텍스트만 나감
💡 꿀팁: 5장 이상이면 자동 배분됨 (입고/전/중/후/후)
Tier 3 — 보너스 (프리미엄 블로그)
9. 고객 증상 보너스
→ consumer.directDemand.symptom
뭘 기록?
고객이 말한 증상 그대로
예시
"브레이크 밟을 때 끝까지 밀려요", "고속에서 핸들이 떨려요"
블로그 효과
"증상 공감형" 도입부 활성화 + 증상 해시태그 매칭 (#브레이크떨림 등)
10. 소개/레퍼럴 보너스
→ salesContext.referral
뭘 기록?
어떤 경로로 왔는지
예시
"BMW 동호회 추천", "지인 소개"
블로그 효과
"고객 스토리형" 블로그 활성화 — 감성적 서사 구조
11. 무료 서비스 보너스
→ salesContext.freeServices
뭘 기록?
추가로 해준 것
예시
시운전, 하체점검, 브레이크액 보충, 세팅 조정
블로그 효과
"가성비형" 앵글 활성화 — 무료 서비스 자연스럽게 어필
12. 고객 지역 보너스
→ salesContext.customerRegion
뭘 기록?
고객이 어디서 왔는지
예시
"대전에서 방문", "부산에서 택배 장착"
블로그 효과
전국 고객 신뢰도. 로컬 SEO 팩트시트에 포함

블로그 타입 결정 플로차트

난이도 "상" + 커스텀 작업? → 🔧 기술 심화형
스펙 비교 있음? → 📊 부품 비교형
소개/레퍼럴 있음? → 💬 고객 스토리형
난이도 "하~중"? → 📖 유지보수 가이드형
기본 → 📋 사례 연구형
