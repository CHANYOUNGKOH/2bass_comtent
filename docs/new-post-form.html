1. 차량 정보
  • 브랜드/모델은 정확하게 (예: "그랜저 TG" O, "그랜저" △)
  • 연식, 주행거리, 특이사항 기록하면 글 신뢰도 UP
2. 작업 정보
  • 고객이 말한 증상 그대로 적기 (예: "브레이크가 물렁해요")
  • 작업 중 발견한 예상 못한 문제
  • 특이한 차량 상태 (녹, 이전 작업 흔적 등)
  • 해결 과정에서의 판단 근거
3. 작업 메모
  • 왜 이 부품/방식을 선택했는지 이유
  • 다른 샵이라면 어떻게 했을지 (차별점)
  • 고객이 한 말 (한마디라도 OK)
  • 작업 중 까다로웠던 포인트
4. 추가 정보
  • 순정 대비 체감 차이 (수치면 더 좋음)
  • 무료로 해준 서비스 (시운전, 점검 등)
  • 고객이 어디서 왔는지 (지역 → SEO 효과)
  • 소개/동호회 경로 (스토리 앵글 활성화)
5. 사진

  • 작업 전/후 비교 사진이 가장 효과적
  • 부품 디테일 컷도 전문성 어필에 좋음
